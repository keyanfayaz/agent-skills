# Setup preferences

- Put shared project conventions in the project's instructions, such as `AGENTS.md` for Codex or `CLAUDE.md` for Claude Code. Keep personal defaults in your host's user instructions.
- Keep the instructions short. Record preferences that change the work, such as when to write docstrings or how much detail to include in a PR.
- Copy the relevant guidance from [coding style](coding-style.md) into those instructions, or link to a copy of the reference that is available wherever the agents run.
- Apply explicit task requests first, then project conventions, then personal defaults.
- When asked to update preferences, preserve existing instructions and report where the new guidance is saved.
